DANNY'S HANGOUT WEBSITE — HOW TO PUT IT ONLINE
==============================================

1. SET UP THE SECRET ADMIN
   a) Rename the folder "secret-admin" to something random that only you
      know, e.g. "x7k2folder9q".
   b) Open config.php in Notepad and set:
        ADMIN_SECRET   = a random key, letters and numbers, 12+ characters
        ADMIN_PASSWORD = your password (8+ characters)
      (Advanced: put a password hash in ADMIN_PASSWORD_HASH instead, so the
       password itself is never written in the file.)

2. YOUR SECRET ADMIN LINK
       yoursite.com/FOLDER-NAME?SECRET-KEY
   Bookmark it. Without the key the folder shows a normal "page not found",
   so nobody can tell the admin exists. After the link you still need the
   password. "Log out" locks it again. 10 wrong passwords = locked for 1 hour.

3. UPLOAD WITH FILEZILLA
   - Connect to your host.
   - On the right side, open your website folder (often called
     public_html, htdocs or www).
   - Drag EVERYTHING inside this folder (not the folder itself) into it.
     Turn on hidden files so the .htaccess files go too
     (FileZilla: Server > Force showing hidden files).
   - UPDATING an older version? Upload everything EXCEPT the data and
     uploads folders, so you keep your clips, votes and settings.
     Delete the old admin.php from your host if it is still there.

4. FOLDER PERMISSIONS
   These folders must be writable:  data  uploads  uploads/clips  uploads/builds  uploads/sounds
   In FileZilla: right-click each one > File permissions > 755
   (if uploading clips then fails, try 775).

5. TEST IT
   - yoursite.com                       -> home page with the pixel world
   - yoursite.com/FOLDER-NAME           -> should say "page not found"
   - yoursite.com/FOLDER-NAME?KEY       -> login screen
   - Upload a test clip on yoursite.com/spinner, approve it in admin.

HANDY LINKS TO SAY ON STREAM / PUT IN BIO
   yoursite.com/discord      -> goes straight to the Discord invite
   yoursite.com/tiktok       -> goes to the TikTok
   yoursite.com/spinner -> the clip wheel

LIVE TRACKER (yoursite.com/live, "Live" in the menu)
   The site reads Yokii's public TikTok page by itself: when he's live you
   get the red LIVE banner on every page, the viewer count, peak viewers,
   a viewers-over-time chart, the all-time top viewer count, followers,
   likes and a history of every stream. No switch to flip.
   - It checks TikTok at most once a minute, whenever someone visits.
   - TIP for perfect stats even when nobody is on the site: in your host's
     control panel, add a "cron job" that runs every 2 minutes:
         curl -s https://yoursite.com/api.php?a=live > /dev/null
   - Streams from before the site existed (like the 311-viewer one) can be
     added by hand in admin > Live tracker > Add a past stream.
   - Needs PHP with curl (almost every host has it). If TikTok blocks your
     host, admin > Live tracker shows a warning; you can then still use
     "Force the LIVE banner".

YOKII-PEDIA (yoursite.com/yokii-pedia)
   Inside jokes and catchphrases with an optional sound. Add them in
   admin > Yokii-pedia. Entries with a sound also go on the soundboard.

CLIP SPINNER: ANY CLIP
   People can upload any video file (MP4, MOV, WEBM, MKV, AVI, GIF…) or
   paste a link from TikTok, YouTube/Shorts, Twitch, Instagram, Streamable,
   Medal, Kick, X, Discord, or any other site. Known sites play right on
   the wheel; other links get a "Watch it there" button.

LIVE COLLECTOR: CHAT, TOP VIEWERS AND GIFTS, ALL AUTOMATIC
   TikTok doesn't let websites read the live, so a small "live collector"
   runs in a normal browser tab that has the live open (Yokii's PC or a
   mod's). Every 10 seconds it sends what it sees to the site:
     - chat messages  -> "Most said in chat" top 5 on the Live page
     - who chats      -> Top Viewers (most active in chat)
     - gifts          -> Top Donators (in TikTok coins) + gifts on the Live page
   Setup (once): admin > Most said in chat > "Set up the live collector".
   Install the free Tampermonkey extension, paste the script, done. During
   streams just keep tiktok.com/@yokii_fn.alt/live open in that browser.
   - Rude messages or names: click "Hide" in admin.
   - Gift worth wrong / unknown gift: admin > Top donators > Gift coin values.
   - Badge says "waiting for chat…" on a real stream? Click the badge: it
     copies a report. Send that report so the script can be fixed.

BACKUPS
   Admin > "Download a backup" (top of the admin page) saves everything the
   site remembers (settings, polls, donators, stream stats, chat counts) in
   one file. Do it now and then, and before big updates.

SEARCH ENGINES
   yoursite.com/sitemap.xml and /robots.txt are made automatically, so
   Google can find every page (never the admin or the Vault).

WHAT TO DO IN ADMIN
   - Live tracker: see stats, add past streams, force the banner if needed
   - Chat top 5: counted automatically by the chat collector (see below)
   - Polls: create, edit, reset votes, set an automatic closing time
   - Yokii-pedia: add inside jokes + sounds
   - Clips: approve or delete uploaded clips before they hit the wheel
   - Polls: make "what should I do next stream?" polls
   - Leaderboard: one line per person, "name | score | note"
   - Top donators: one line per person, "name | amount | note".
     #1 gets the crown on the home page. Check TikTok LIVE top gifters
     after each stream and update it.
   - Clip wall: paste his best TikTok video links for the home page
   - Builds: upload screenshots of builds from breezevanilla.eu
   - Settings: next giveaway + end date (countdown), server (breezevanilla.eu), seed of the week,
     his Minecraft username (skin viewer), schedule text, and the
     VAULT SECRET WORD (see below).

==============================================
 🤫 SPOILERS: ALL THE SECRETS (for you and him only)
==============================================
Visitors earn XP and achievements (green XP bar at the bottom of every
page, click it to see them). Progress is saved in their browser.

THE VAULT: after 5 achievements a hidden page opens: yoursite.com/vault
It shows the "Vault secret word" you set in admin. Tell people in Discord:
"type the secret word in #vault to get the Vault Hunter role". Change the
word now and then. (Make a #vault channel and a role for it in Discord.)
Note: the word isn't truly uncrackable, a tech-savvy person could find it,
so use it for fun roles, not real prizes.

Secret achievements and Easter eggs:
  - Mine the ground on the home page (click the blocks). 64 blocks = secret.
    Rare diamond ore in the stone = secret.
  - Hidden diamonds: sometimes a tiny diamond hides in a corner of a box
    on any page. Click it. 5 found = Diamond Hoarder.
  - Konami code on the keyboard: ↑ ↑ ↓ ↓ ← → ← → B A  -> the page explodes
  - Click the logo (top left) 10 times -> also explodes
  - Type "herobrine" anywhere -> something stares at you
  - Type "diamond", "danny", "party" or "boom" for little surprises
  - Visit between midnight and 5 AM -> Night Owl (+ maybe a visitor…)
  - Clip wheel: 1 in 30 spins is a GOLDEN SPIN
  - Visit 3 days in a row -> Regular
  - Catch Danny game (Games page): score 25+
  - The home page sky follows the visitor's real time: day, sunset, night
  - Open the browser console (F12) for a hidden message

Tease these on stream ("there are secret achievements on the site, first
person to find the Vault gets a shoutout") to get people to the site
and into the Discord.

NEEDS: a host with PHP 8.0 or newer (almost every normal web host).
If clip uploads say "too big", your host limits upload size. Ask them to
raise upload_max_filesize / post_max_size, or people can paste TikTok links.

If you change the Discord invite later, also edit discord/index.html.
The custom "page not found" needs the site in the main folder of your
domain (not in a subfolder).
