Download for Windows Other versions

Downloads the installer (.exe) directly - just run it, no command line needed. Your browser may warn the file isn't commonly downloaded (click the arrow next to Delete/Discard and choose Keep), and Windows SmartScreen may warn too since it isn't code-signed - click "More info → Run anyway". Both are normal for a free, unsigned app.

What it does

Everything you need, nothing you don't

No ads, no bloat - just the parts of a launcher that actually matter for playing modded Minecraft.

⚙️

Every mod loader

Fabric, Forge, Quilt, and NeoForge, all installed and launched automatically per instance.

🔍

Built-in Modrinth browsing

Search and install mods, resource packs, shaders, and full modpacks straight from the launcher - dependencies resolve themselves.

👥

Import an existing setup

Already using the Modrinth App? Import your exact mod list by matching file hashes - no manual searching.

🎨

Five full themes

Pick an accent color and the whole app repaints - palette, icon, and an animated backdrop scene - each with light and dark variants.

👤

Multiple accounts & instances

Switch Microsoft accounts on one PC, and keep as many separate instances as you want - one per modpack or per group you play with.

🔄

Updates itself

New versions download in the background and install on restart - no reinstalling, no chasing download links.
