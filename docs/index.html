A Minecraft launcher built
for your friend group

Every friend runs the same mods without a shared server. Built-in Modrinth browsing, one-click modpacks, and five fully themed looks - desert, jungle, volcano, ocean, or space.

Download for Windows Other versions

Downloads the installer (.exe) directly - just run it, no command line needed. Windows SmartScreen may warn since it isn't code-signed - click "More info → Run anyway".

What it does

Everything a group needs, nothing you don't

No ads, no bloat - just the parts of a launcher that actually matter for playing modded Minecraft together.

⚙️

Every mod loader

Fabric, Forge, Quilt, and NeoForge, all installed and launched automatically per instance.

🔍

Built-in Modrinth browsing

Search and install mods, resource packs, shaders, and full modpacks straight from the launcher - dependencies resolve themselves.

👥

Import a friend's setup

Already using the Modrinth App? Import your exact mod list by matching file hashes - no manual searching.

🎨

Five full themes

Pick an accent color and the whole app repaints - palette, icon, and an animated backdrop scene - each with light and dark variants.

👤

Multiple accounts & instances

Switch Microsoft accounts on one PC, and keep as many separate instances as you want - one per modpack or per friend group.

🔄

Updates itself

New versions download in the background and install on restart - no reinstalling, no chasing download links.
