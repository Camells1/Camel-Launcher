Camel Crosshairs
Camel Launcher Features GitHub
Free · Windows

Put a crosshair
on any game

A small always-on-top overlay for games that don't come with a crosshair. 100 built-in presets, fully custom shapes and colors, or upload your own image - lives quietly in the system tray.

Download for Windows Other versions

Downloads the installer (.exe) directly - no admin rights needed. Your browser may warn the file isn't commonly downloaded (click the arrow next to Delete/Discard and choose Keep), and Windows SmartScreen may warn too since it isn't code-signed - click "More info → Run anyway". Both are normal for a free, unsigned app.

What it does

One small app, stays out of the way

Runs from the system tray using almost no resources. No game files are touched.

🎯

100 built-in presets

20 colors × 5 shapes, ready to go - or dial in your own size, thickness, gap, and outline.

🖼️

Use your own image

Upload any picture and use it as your crosshair instead of a drawn shape.

🖱️

Hides your real cursor

Optionally replaces the system cursor so your crosshair is the only thing on screen - always restored on exit.

📌

Always on top

Sits above any game or app running in windowed or borderless mode.

🎨

Six themes

The same accent colors as Camel Launcher, right down to Starburst.

🔔

Lives in the tray

Toggle it on/off or open settings from the tray icon - no taskbar clutter, no background window.

Try the theme

Same picker as the Camel Launcher site - pick a color, pick light or dark.
